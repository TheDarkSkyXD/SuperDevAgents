On GitHub Copilot, load superdev skills by their bare names through the `skill` tool (`superdev-mode`, `tdd`, `architect`, not `superdev:superdev-mode`); the plugin's agents keep the prefix (`superdev:superdev-agent`, `superdev:comment-sicko`). Copilot lists only part of a large plugin's skills in its prompt; every superdev skill a workflow names still loads by that name. `.github/copilot-instructions.md` and `~/.copilot/copilot-instructions.md` count as user instructions. Resolve every Claude tool, model, path, and built-in skill a superdev skill names through `references/copilot-tools.md` in the `superdev-mode` skill directory. superdev ships no default Copilot models. A skill that dispatches on role models takes them from the user's saved superdev model choices. The plugin hook reads them from the Copilot model sheet, `${COPILOT_HOME:-~/.copilot}/superdev-models.md`, checks them, and adds them to the end of this block. Do not `view` the sheet. It sits outside the workspace, so reading it asks for path access. After `superdev-setup` writes the sheet in this session, use the values it just wrote.

Skills that dispatch on role models: `architect`, `arena`, `how`, `interrogate`, `reflect`, `superdev-mode`, `swarm`, `why`.
