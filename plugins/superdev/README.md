# SuperDev plugin

SuperDev combines portable engineering skills with native adapters for Claude Code, Codex, GitHub Copilot, Pi, and Muse. Read the [repository README](../../README.md) and [harness setup](../../docs/harnesses.md) for installation.

The canonical skills live in this directory. The repository-local `.agents/` bundle is generated from these files. See [NOTICE.md](../../NOTICE.md) for copyright and license notices.
